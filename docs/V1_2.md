# Version 1.2 — customizable typography

- Two or three configurable visual lines. The third line is retained when switching to two-line mode.
- Choose Japanese word, kana reading, meaning, combinations, an empty slot or custom text per line. Templates support {word}, {reading}, {meaning} and literal text; tokens refresh with each vocabulary word.
- Per-line Sans, Serif, Monospace or Rounded system font; bold, size, #RRGGBB color and left/center/right alignment. Global font updates all rows; Default line alignment follows block alignment.
- Top / Middle / Bottom presets plus the continuous position slider. Middle is the new-install default; existing saved positions are preserved.
- Line spacing, global size and background-panel opacity controls.
- Live pinned and expanded preview. Per-line edits are drafts until Save line layout or Save & apply. Drafts survive tab changes while the ViewModel lives; save before closing the app. Export is disabled for an unsaved layout. Position/global-size/panel sliders still save on release.
- Saved layouts are used for PNG exports, manual wallpaper updates, timers and screen-off updates. Legacy reading/meaning visibility preferences migrate when no custom layout is saved.

One slot is one visual line. Empty/hidden-reading slots do not consume height. Long text is shrunk to a readable minimum; very long content is ellipsized. This does not add dictionary word editing or custom/downloaded font-file import. Japanese system font fallbacks vary by device. Invalid hex input leaves the last valid color active. Choose colors with sufficient contrast against your image.
