# Kumo 1.9.0

## Kanji identity

- The app icon is now the kanji 雲 (kumo, cloud) in white on Kumo blue #235BB5, replacing the cloud pictogram.
- The new mark is used everywhere: vector fallback for API 24–25, adaptive foreground for API 26+, monochrome themed icon for API 33+, and the notification silhouette.
- Brand sources updated: `branding/kumo-icon.svg` and the new `branding/kumo-kanji.svg`. Outlines were converted from Noto Sans JP Bold (SIL Open Font License 1.1); no font is bundled or needed at runtime for the icon.

## Appearance switcher

- The top bar has a new light/dark/system switcher immediately before the info button. Tapping it moves to the next appearance and confirms the change.
- The choice is stored on the device, so Kumo reopens in the appearance you picked; System keeps following Android, including changes made while the app is open.
- Status and navigation bar icons follow the selected appearance. Material You dynamic colour still applies on Android 12+, and the Kumo blue palette is still used on older releases.

## Releases on GitHub

- New **Kumo version release** workflow publishes a GitHub release for every version bump on `main`, tagged `v<versionName>`.
- Notes come from `docs/releases/v<versionName>.md` when the file exists, and from generated notes otherwise. An existing tag or release is never overwritten.
- Signed APK/AAB artifacts still come from the production workflow described in `docs/PRODUCTION_RELEASE.md`.
