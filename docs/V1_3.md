# Version 1.3 — Japanese fonts and JLPT library

## Changes
- Dark panel defaults to 0%. On the first 1.3 settings save, the old 40% value migrates to 0%; other saved values are retained. The panel slider still allows custom opacity.
- Horizontal crop slider removed. Vertical crop remains; Center photo resets both axes. Existing photo data is preserved.
- Generic font aliases replaced by bundled Gothic JP (Zen Kaku Gothic New) and Mincho JP (Zen Old Mincho), with true regular/bold files. Existing Serif maps to Mincho; other old selections map to Gothic. Preview and final bitmap use the same asset-backed typefaces. Four static fonts total about 15.6 MB before APK compression.
- Words supports any combination of N5–N1. Counts show locally available entries. Download / refresh selected levels requests full lists from the public no-key JLPT Vocabulary API.
- Include starter pack (ungraded), Favorites only, per-word favorites, shuffle, Japanese/English search, download progress, retry through Download / refresh, cached date and empty/error states.
- Level/favorite filters control both Words and wallpaper rotation. Search filters browsing only. Empty eligible pools do not silently use another level: Apply/export are disabled and background work reports an actionable error.
- Downloads are explicit and off the UI thread; no network-held wallpaper mutex. Complete validated responses replace private atomic cache files. Failed requests retain previous cache. Rotation does not need internet. Stable word IDs preserve selection/favorites across restarts. New records append to keep indices stable in a live session; removed upstream records may remain until restart.

## Use
1. Words: choose levels, then Download / refresh selected levels. N5 is initially selected.
2. Disable Include starter pack for strictly level-filtered study. Favorites only needs a starred word in the selected levels.
3. Studio: choose Gothic JP or Mincho JP under Line designer, then Save line layout / Save & apply.
4. Enable screen-off updates in Schedule if desired. They use cached, eligible words, with no API call on screen-off.

## Build and validation
Version 1.3.0 / versionCode 4. Existing CI workflow unchanged. Gradle prepareJapaneseFonts downloads original font/license files from pinned google/fonts commit 5e35378e6bda803962ee6fd257e444a7d459660d, verifies Git blob hashes and packages assets. Missing/invalid fonts fail the build instead of silently falling back. First builds need internet; later builds reuse valid generated files until clean.

The generation sandbox has no reachable network, SDK or emulator. Static source checks passed. API documentation/handler source were inspected, but a live vocabulary response could not be verified. New JVM tests cover filters, empty pools, shuffle, defaults and parsing; a device test checks that fonts produce different glyphs. Compilation, lint, JVM/device tests and actual visual/font/network operation require CI/device verification. Source checks are not a successful Android build or visual QA.

## Data and privacy
Provider: https://jlpt-vocab-api.vercel.app/ by wkei, with study data from Jonathan Waller/Tanos. Lists are third-party study classifications, not an official JLPT vocabulary syllabus; accuracy and uptime are not guaranteed. Downloads expose requested level and normal network metadata (including IP) to the provider. No photos, settings, account or analytics payloads are uploaded. Cached words stay in private app storage. See THIRD_PARTY_NOTICES.md before redistributing provider data.

## Acceptance
Test panel/font-name migration; retained photo/position; Gothic/Mincho and regular/bold in preview/export/lock screen; each level download and multiple-level filtering; offline restarts; selected word/favorite persistence; empty favorites; zero selected levels; provider errors/invalid JSON; no network requests on screen-off. Debug APK signing keys can differ between GitHub-hosted builds: uninstalling to resolve a signature mismatch deletes saved photo/settings/cache, so preserve anything needed first.
